# MCP bin vs `@hyperdag/trustshell-mcp@1.0.0`

Two different MCP servers share a similar name. The **SDK bin** `trustshell-mcp` is this repo (`DealAppSeo/trustshell` `src/mcp/index.ts` → `dist/mcp/index.js` after `npm run sdk:build`). Published `@hyperdag/trustshell@1.3.0` ships that bin with `verify` / `getLeaderboard` / `getRepID` only — **no `present_proof`** [verified unpkg 1.3.0 `dist/mcp/index.js`]. `present_proof` on that bin lives in the unpublished **1.4.0 git tree** of this same file. The **separate npm package** `@hyperdag/trustshell-mcp@1.0.0` is not that bin: it already registers `present_proof` (plus `verify_output`, `get_repid`, `verify_proof`, `list_services`, `buy_service`) [verified unpkg 1.0.0 `dist/index.js`]. `npx @hyperdag/trustshell-mcp@1.0.0` will not unknown-tool `present_proof`. Do not document `npx @hyperdag/trustshell@1.4.0`; 1.4.0 is not on npm.
