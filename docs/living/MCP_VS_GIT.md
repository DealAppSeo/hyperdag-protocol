# MCP bin vs `@hyperdag/trustshell-mcp@1.0.0`

The npm package `@hyperdag/trustshell-mcp@1.0.0` is the **published** MCP server: `verify`, `getRepID`, `getLeaderboard` only. `present_proof` is **not** on that tarball. It lives in this git tree (`DealAppSeo/trustshell` `src/mcp/index.ts`, unpublished 1.4.0). After `npm run sdk:build` in a clone, the bin is `trustshell-mcp` → `dist/mcp/index.js`. `npx @hyperdag/trustshell-mcp@1.0.0` will answer unknown tool for `present_proof` — that is the package, not a broken clone. Do not document `npx @hyperdag/trustshell@1.4.0` either; 1.4.0 is not on npm.
